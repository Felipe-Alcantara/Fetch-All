# Política de segurança

## Relatar uma vulnerabilidade

Não publique detalhes exploráveis, credenciais ou dados de repositórios em uma
issue pública. Se disponível, use **Report a vulnerability** na aba Security
do repositório no GitHub. Caso o recurso não apareça, contate o mantenedor pelo
perfil indicado no README e solicite um canal privado antes de compartilhar os
detalhes. Inclua uma descrição curta, impacto, passos mínimos para reproduzir e
a versão afetada.

O mantenedor buscará confirmar o recebimento e avaliar o relato antes de
qualquer divulgação pública. Não há prazo de correção garantido para este
projeto pessoal, mas relatos responsáveis serão priorizados.

## Escopo de segurança

O Fetch All executa Git nos repositórios encontrados e pode realizar pull,
push e, mediante confirmação separada, commit automático. Relatos sobre
execução sem confirmação, perda de dados, exposição de credenciais em saída ou
relatórios e travessia indevida de caminhos estão dentro do escopo.
